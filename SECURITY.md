# Security policy

## Supported versions

| Version | Status  | Security fixes |
| ------- | ------- | -------------- |
| v0      | Current | Yes            |

## Reporting a vulnerability

Do not open a public Issue. Report it privately through GitHub: [Report a vulnerability](https://github.com/d-zero-dev/nitpicker/security/advisories/new). Include the affected version, how to reproduce it, and the impact you expect.

A fix is released for every supported version that is affected, and the advisory is published with the release.
