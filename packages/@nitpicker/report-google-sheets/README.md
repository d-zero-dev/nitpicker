# @nitpicker/report-google-sheets

`.nitpicker` アーカイブのクロール結果と分析結果をGoogle Sheetsへ出力する内部パッケージです。

通常は [@nitpicker/cli](../cli/README.md) の `report` コマンドから利用します。
