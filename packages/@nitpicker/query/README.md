# @nitpicker/query

`.nitpicker` アーカイブを開き、ページ、リンク、リソース、分析結果などを問い合わせる関数群です。

通常は [@nitpicker/cli](../cli/README.md) の `query` コマンド、または [@nitpicker/mcp-server](../mcp-server/README.md) 経由で利用します。
